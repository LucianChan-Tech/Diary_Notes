# FocusTasked 项目说明

当前工程目录：`FocusTasked_V0.1.15.3/`  
当前应用版本：`0.1.15.3`  
当前目标 SDK：`5.0.0(12)`

## 项目简介
`FocusTasked` 是一个基于 HarmonyOS NEXT 与 ArkTS 开发的本地任务管理应用，当前版本围绕“按日期管理个人任务”展开，支持本地账号登录注册、日历视图、任务增删改查、优先级管理、完成状态切换，以及基于本地 `preferences` 的数据持久化。

当前主流程如下：

1. 用户进入登录页。
2. 已注册用户输入用户名、账号、密码后进入主页。
3. 新用户可先注册，再登录进入主页。
4. 在主页中按日期查看、管理和搜索历史任务。

## 当前已实现功能
### 1. 登录与注册
- 登录页面位于 `entry/src/main/ets/pages/LoginPage.ets`
- 支持本地账号登录
- 支持新账号注册
- 注册时校验用户名、账号、密码和确认密码
- 登录时校验账号是否存在、用户名是否匹配、密码是否正确

### 2. 用户会话管理
- 当前登录用户由 `UserSessionRepository` 管理
- 登录成功后保存当前用户会话
- 退出登录后清空会话并返回登录页

### 3. 日历任务主页
- 主页面位于 `entry/src/main/ets/pages/MainPage.ets`
- 顶部显示应用标题、当前用户与各等级未完成任务统计
- 支持按月切换日历
- 支持选中某一天查看该日期下的任务
- 有任务的日期会在日历中显示标记点

### 4. 任务管理
- 点击右下角 `+` 按钮可为当前选中日期新增任务
- 任务支持新增、编辑名称、修改优先级、标记完成/未完成、删除
- 任务列表按优先级显示，顺序为 `S -> A -> B -> C`
- 同级任务按创建顺序稳定展示

### 5. 历史任务搜索
- 主页面底部提供“搜索历史任务”入口
- 支持按任务内容做模糊匹配
- 支持按 `全部 / S / A / B / C` 等级筛选
- 单条命中时直接跳转到对应日期
- 多条命中时展示结果列表，点击后跳转到目标日期

### 6. 优先级规则
任务等级定义位于 `entry/src/main/ets/model/TaskModel.ets`，当前包含四个等级：

- `S`：最高优先级
- `A`：较高优先级
- `B`：中等优先级
- `C`：较低优先级

自动分级规则如下：

- 当天第 1 条任务自动分配为 `S`
- 当天第 2 条任务自动分配为 `A`
- 当天第 3 条任务自动分配为 `B`
- 当天第 4 条及之后的任务自动分配为 `C`

同时，新建任务时也支持手动指定等级，后续还可再次编辑任务名称和等级。

### 7. 本地数据持久化
项目通过 `entry/src/main/ets/model/AppRepository.ets` 管理数据读写，主要包括：

- 账号数据持久化
- 当前登录用户持久化
- 各用户各自的任务数据持久化

当前使用 HarmonyOS 的 `preferences` 存储能力进行本地保存，同时保留了旧版 `AppStorage` 数据迁移逻辑，用于兼容历史数据。

## 代码结构
### `entry/src/main/ets/pages/`
页面层代码，负责界面展示和交互逻辑。

- `LoginPage.ets`：登录页面，处理登录、注册入口与提示逻辑
- `MainPage.ets`：主功能页面，包含月历、任务统计、任务列表、历史搜索、退出登录与新增任务入口
- `PopupPage.ets`：弹窗宿主组件，用于承载欢迎、注册、任务新增、任务编辑、删除确认与历史搜索弹窗
- `TaskItemView.ets`：单条任务展示组件

### `entry/src/main/ets/model/`
模型层与数据逻辑层。

- `TaskModel.ets`：定义任务等级、任务实体、任务创建/编辑/排序/统计/搜索等方法
- `AppRepository.ets`：定义账号仓库、任务仓库和用户会话仓库，负责本地存储初始化、序列化和迁移
- `PopupTypes.ets`：定义弹窗类型及其配置

### `entry/src/main/ets/entryability/`
- `EntryAbility.ets`：应用入口 Ability

## 数据设计
### 账号数据
账号数据由 `AccountRepository` 管理，每个账号包含：

- 用户名
- 用户账号
- 密码

### 任务数据
任务数据由 `Task` 类描述，每条任务包含：

- `id`：任务唯一标识
- `title`：任务标题
- `level`：任务等级
- `date`：所属日期，格式为 `YYYY-MM-DD`
- `completed`：是否完成
- `insertionIndex`：该任务在当天的插入顺序

### 用户任务隔离
不同用户的任务通过用户账号分桶存储，每个用户只能读取和操作自己的任务列表。

## 运行与构建
建议使用 DevEco Studio 打开 `FocusTasked_V0.1.15.3/` 作为工程根目录。

- `Build > Build Hap(s)/APP(s) > Build APP(s)`：构建应用
- `Run > Run 'entry'`：安装并启动应用
- `Previewer`：可用于快速查看 UI，但登录、路由、存储行为应以真机或模拟器验证为准

如果本地已经配置 HarmonyOS 构建工具，也可使用 `hvigor` 任务构建。

## 当前状态
当前代码已形成“登录/注册 + 日历 + 分级任务管理 + 历史任务搜索 + 本地存储”的闭环。

当前适合继续扩展的方向包括：

- 搜索结果进一步筛选，例如按完成状态过滤
- 更完整的异常提示与输入校验
- 更细化的 UI 交互动效与视觉优化
