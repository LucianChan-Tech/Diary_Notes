# FocusTasked 项目说明

当前工程目录：`FocusTasked_V0.1.15.3/`
当前应用版本：`0.1.15.3`
当前目标 SDK：`5.0.0(12)`

## 项目简介
`FocusTasked` 是一个基于 HarmonyOS NEXT 与 ArkTS 开发的轻量级任务管理应用，当前版本围绕“按日期管理个人任务”展开。项目已经实现了本地登录注册、日历视图、任务增删改查、任务完成状态切换，以及本地持久化存储等基础能力。

当前界面已统一使用 `FocusTasked` 作为应用显示名，应用图标与登录页顶部图标已切换为同一套资源，主强调色已调整为更贴近图标的 `#FF2F5D`。

当前主流程如下：

1. 用户进入登录页面。
2. 已注册用户输入用户名、账号和密码后进入主页面。
3. 新用户可先注册，再登录进入主页面。
4. 在主页面中按日期查看和管理当天任务。

## 当前已实现功能

### 1. 登录与注册
- 登录页面位于 `entry/src/main/ets/pages/LoginPage.ets`
- 支持本地账号登录
- 支持新账号注册
- 注册时校验用户名、账号、密码和确认密码
- 登录时校验账号是否存在、用户名是否匹配、密码是否正确
- 当前版本未实现找回密码

### 2. 用户会话管理
- 当前登录用户由 `UserSessionRepository` 管理
- 登录成功后会保存当前用户信息
- 退出登录后会清空当前会话并返回登录页

### 3. 日历任务主页
- 主页面位于 `entry/src/main/ets/pages/MainPage.ets`
- 顶部显示应用标题与当前登录用户
- 支持按月切换日历
- 支持选中某一天查看该日期下的任务
- 当某一天存在任务时，日历对应日期会显示标记点
- 顶部统计卡会显示 `S / A / B / C` 四个等级的未完成任务数量

### 4. 任务管理
- 点击右下角 `+` 按钮可为当前选中日期新增任务
- 任务支持新增、修改优先级、标记完成/未完成、删除
- 任务列表按优先级显示，顺序为 `S -> A -> B -> C`
- 同级任务按创建顺序稳定展示

### 5. 优先级规则
任务等级定义位于 `entry/src/main/ets/model/TaskModel.ets`，当前包含四个等级：

- `S`：最高优先级
- `A`：较高优先级
- `B`：中等优先级
- `C`：较低优先级

自动分级规则如下：

- 当天第 1 条任务自动分配为 `S`
- 当天第 2 条任务自动分配为 `A`
- 当天第 3 条任务自动分配为 `B`
- 当天第 4 条及之后的任务自动分配为 `C`

同时，新增任务时支持手动指定等级，后续还可再次编辑等级。

### 6. 本地数据持久化
项目通过 `entry/src/main/ets/model/AppRepository.ets` 管理数据读写，主要包括：

- 账号数据持久化
- 当前登录用户持久化
- 各用户各自的任务数据持久化

当前使用的是 HarmonyOS 的 `preferences` 存储能力，数据以本地方式保存。代码中还保留了旧版 `AppStorage` 数据迁移逻辑，用于兼容历史数据。

## 代码结构

### `entry/src/main/ets/pages/`
页面层代码，负责界面展示和交互逻辑。

- `LoginPage.ets`
  登录页面，处理登录、注册入口、密码显示切换和结果提示。
- `MainPage.ets`
  主功能页面，包含月历、任务统计、任务列表、退出登录和任务弹窗等逻辑。
- `PopupPage.ets`
  弹窗宿主组件，用于承载注册、新增任务、编辑等级、删除确认和欢迎提示。
- `TaskItemView.ets`
  单条任务展示组件，负责显示任务标题、等级、完成状态以及编辑删除入口。

### `entry/src/main/ets/model/`
模型层与数据逻辑层。

- `TaskModel.ets`
  定义任务等级枚举 `TaskLevel`、任务实体 `Task`，以及任务创建、排序、统计和状态切换等方法。
- `AppRepository.ets`
  定义账号仓库、任务仓库和用户会话仓库，负责本地存储初始化、序列化、反序列化和旧数据迁移。
- `PopupTypes.ets`
  定义弹窗类型和弹窗配置，服务于任务新增、编辑、删除确认和注册流程。

### `entry/src/main/ets/entryability/`
- `EntryAbility.ets`
  应用入口 Ability。

## 数据设计

### 账号数据
账号数据由 `AccountRepository` 管理，每个账号包含：

- 用户名
- 用户账号
- 密码

### 任务数据
任务数据由 `Task` 类描述，每条任务包含：

- `id`：任务唯一标识
- `title`：任务标题
- `level`：任务等级
- `date`：所属日期，格式为 `YYYY-MM-DD`
- `completed`：是否完成
- `insertionIndex`：该任务在当天的插入顺序

### 用户任务隔离
不同用户的任务通过用户账号分桶存储，每个用户只能读取和操作自己的任务列表。
